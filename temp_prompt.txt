OBJECTIF (demande d'origine)
----------------------------
PARTIE 1 : fiabiliser l'état « à jour » des pilotes
- Trois états : « À jour (vérifié) », « Mise à jour disponible », « Non vérifiable ».
  Un pilote sans source fiable ne doit JAMAIS apparaître comme à jour.
- Comparer la version installée à la dernière version publiée par la source officielle quand elle existe
  (NVIDIA, Dell, HP, Lenovo, Windows Update).
- Afficher pour chaque pilote la source utilisée et la date de la vérification.
PARTIE 2 : un vrai lien de téléchargement pour chaque pilote
- Bouton « Télécharger » qui ouvre la page la plus précise : fichier ou page exacte si la source la fournit,
  sinon page de support pré-remplie (modèle de carte mère / de PC, ID matériel).
- Structure extensible : une classe par fabricant dans app/core/driver_sources/.
- Jamais de téléchargement ni d'exécution hors domaines officiels ; garder la vérification de signature NVIDIA.
  Pour Dell/HP/Lenovo : on OUVRE le lien dans le navigateur, on ne télécharge/exécute rien soi-même.
- Si une source n'a pas d'API publique (Intel, AMD, Realtek, ASUS, Acer, MSI, Gigabyte, ASRock…),
  le dire dans l'interface plutôt que deviner.
Contraintes : logique dans app/core/ testable avec pytest sans toucher au vrai système ; textes en français ;
aucune donnée personnelle envoyée (pas de numéro de série / service tag : seulement modèle, SKU, ID plateforme) ;
mettre à jour README (tableau des fonctionnalités, Sécurité, Limites connues).
Partie 3 (nouvelles fonctionnalités) : en attente du choix de l'utilisateur, ne pas commencer.

FORMATS DES CATALOGUES OFFICIELS (vérifiés en direct le 24/11/2026)
------------------------------------------------------------------
DELL — https://downloads.dell.com/catalog/CatalogPC.cab (~3 Mo, XML UTF-16 de ~57 Mo une fois extrait :
  utiliser ET.iterparse + elem.clear()). Racine <Manifest baseLocation="downloads.dell.com">.
  <SoftwareComponent releaseID="025D7" path="FOLDER.../X.EXE" vendorVersion="3.11.100.7733"
     dellVersion="A00" releaseDate="March 31, 2026" size="...">
    <Name><Display>…</Display></Name>
    <ComponentType value="DRVR"> (ne garder que DRVR)
    <Category value="CS"><Display>Chipset</Display></Category>
    <SupportedDevices><Device><PCIInfo deviceID="7745" vendorID="8086" subDeviceID="" subVendorID=""/>
      (uniquement PCIInfo)
    <SupportedSystems><Brand><Model systemID="0CF4"><Display>Dell-Pro-13-Plus-PB13250</Display>
  Identifiant du PC = Win32_ComputerSystem.SystemSKUNumber (À AJOUTER dans drivers._query_hardware_vendors
  sous la clé "sku"). Téléchargement : https://downloads.dell.com/<path>.
  Page exacte : https://www.dell.com/support/home/fr-fr/drivers/driversdetails?driverid=<releaseID>
  (renvoie 403 à curl, protection anti-robot ; fonctionne dans un navigateur).
  vendorVersion = version du pilote INF (comparable à DriverVersion WMI) ; prendre la plus récente par périph.

HP — ID plateforme = Win32_BaseBoard.Product (4 hex, ex. 8DE2).
  Liste : https://hpia.hpcloud.hp.com/ref/platformList.cab -> <Platform><SystemID>8DE2</SystemID>
    <OS><OSVersion>10.0</OSVersion><OSReleaseIdFilename>24H2</OSReleaseIdFilename><IsWindows11>true…
  Référence : https://hpia.hpcloud.hp.com/ref/{id minuscule}/{id minuscule}_64_{11.0|10.0}.{release minuscule}.cab
    ex. /ref/8de2/8de2_64_11.0.24h2.cab (MAJUSCULES -> 404). 11.0 si IsWindows11, sinon 10.0.
    Choisir la release de Windows actuelle si listée, sinon la plus récente pour la même version majeure.
  Contenu (UTF-8) : racine <ImagePal> ;
    <Devices><Device><DeviceId>PCI\VEN_…&DEV_…&SUBSYS_…</DeviceId><DriverVersion>1.0.0.333</DriverVersion>
      <Solutions><UpdateInfo IdRef="sp174332"/></Solutions></Device>
    <Solutions><UpdateInfo><Id>sp174332</Id><Name>…</Name><Category>Driver - Audio</Category>
      <Version>…</Version><Url>ftp.hp.com/pub/softpaq/…/sp174332.exe</Url>
      <ReleaseNotesUrl>ftp.hp.com/…/sp174332.html</ReleaseNotesUrl><DateReleased>2026-08-13</DateReleased>
    Attention : root.find("Solutions") = enfant direct (il existe aussi SystemInfo/System/Solutions).
    Dernière version = Device/DriverVersion (pas UpdateInfo/Version, qui est la version du SoftPaq).
    URL sans schéma -> préfixer https:// (ftp.hp.com répond en HTTPS, testé 200).
    Correspondance : SUBSYS identique en priorité, sinon VEN/DEV.

LENOVO — type de machine = 4 premiers caractères de Win32_ComputerSystem.Model (ex. 20XW).
  Catalogue : https://download.lenovo.com/catalog/{MT}_Win11.xml (Win10 si build < 22000 ; essayer l'autre si 404)
    <packages><package><location>https://download.lenovo.com/pccbbs/mobiles/n32li04w_2_.xml</location>
      <category>…</category>
  Descripteur (UTF-8 avec BOM) : <Package name=… id="n32li04w" version="30.100.2129.8"><Title><Desc>…
    <ReleaseDate>2021-10-26</ReleaseDate>
    <DetectInstall><_Driver><HardwareID>PCI\VEN_8086&DEV_A0E8</HardwareID>…<Version>30.100.2129.8^</Version>
    <Files><Installer><File><Name>n32li04w.exe</Name> ; <Readme><File><Name>…
    Téléchargement = dossier de <location> + nom du fichier (testé : 206 OK).
    Ne garder que les paquets avec DetectInstall/_Driver. Récupérer les descripteurs en parallèle (8 threads).
  Page pré-remplie (testée 200) : https://pcsupport.lenovo.com/fr/fr/products/{MT}/downloads/driver-list

PAGES PRÉ-REMPLIES (sans vérification de version)
  ASUS (testé 200) : https://www.asus.com/fr/supportonly/{modèle carte mère/PC encodé}/helpdesk_download/
  MSI : https://fr.msi.com/Motherboard/{modèle sans « (MS-xxxx) », espaces->tirets}/support (403 à curl,
        non vérifiable ici : garder aussi la recherche limitée au site en secours)
  Gigabyte : révision inconnue -> recherche limitée à gigabyte.com
  ASRock, Acer : page support générale + recherche limitée au site
  Intel : page Intel Driver & Support Assistant (outil officiel qui détecte le pilote exact) ;
  AMD : page pilotes + outil de détection automatique AMD ; Catalogue Microsoft par ID matériel pour tous.
  Les URL de vendors.py (support_url, board_drivers_search_url, microsoft_catalog_url) restent utilisables.
